# 🍳 Smart Recipe Buddy

A comprehensive recipe assistant mobile application that generates personalized recipes based on dietary preferences, leftover ingredients, and health goals with integrated calorie tracking.

## ✨ Features

- **🥗 Dietary Preferences**: Customize recipes for vegetarian, vegan, gluten-free, keto, and more
- **📸 Image Recognition**: Scan ingredients using your camera with TensorFlow.js-powered image recognition
- **🤖 AI-Powered Recipe Generation**: Get personalized recipes generated by OpenAI GPT-3.5
- **📊 Calorie Calculator**: Track nutrition information including calories, protein, carbs, and fat
- **💪 Health Goals**: Support for weight loss, muscle gain, heart health, and more
- **📱 Mobile-First Design**: Built with React Native for iOS and Android support

## 🏗️ Technology Stack

- **Frontend**: React Native with TypeScript
- **Navigation**: React Navigation
- **AI/ML**: 
  - OpenAI GPT-3.5 for recipe generation
  - TensorFlow.js for ingredient image recognition
- **State Management**: React Hooks & AsyncStorage
- **Image Processing**: Expo Camera & Image Picker
- **Build Tool**: Expo

## 📋 Prerequisites

- Node.js (v16 or higher)
- npm or yarn
- Expo CLI (`npm install -g expo-cli`)
- OpenAI API Key ([Get one here](https://platform.openai.com/api-keys))
- iOS Simulator (for Mac) or Android Studio (for Android development)

## 🚀 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/ashikbro/smart-recipe-buddy.git
   cd smart-recipe-buddy
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up environment variables**
   ```bash
   cp .env.example .env
   ```
   
   Edit `.env` and add your OpenAI API key:
   ```
   OPENAI_API_KEY=your_openai_api_key_here
   ```

4. **Start the development server**
   ```bash
   npm start
   ```

5. **Run on your device**
   - For iOS: Press `i` in the terminal or scan the QR code with the Expo Go app
   - For Android: Press `a` in the terminal or scan the QR code with the Expo Go app
   - For Web: Press `w` in the terminal

## 📱 Usage

1. **Set Dietary Preferences**
   - Launch the app and tap "Get Started"
   - Select your dietary restrictions (vegetarian, vegan, gluten-free, etc.)
   - Choose your health goals (weight loss, muscle gain, etc.)

2. **Add Ingredients**
   - Manually enter ingredients you have available
   - Or use the "Scan Ingredients" feature to identify ingredients from photos
   - The TensorFlow-powered image recognition will detect ingredients

3. **Generate Recipes**
   - Tap "Generate Recipes" to get personalized recipe suggestions
   - The app uses OpenAI to create recipes based on your preferences and available ingredients

4. **View Recipe Details**
   - See nutritional information for each recipe
   - View prep time, cook time, and serving sizes
   - Expand recipes to see full ingredients and step-by-step instructions

## 🔧 Configuration

### OpenAI API Configuration

The app uses OpenAI's GPT-3.5-turbo model. To configure:

1. Get your API key from [OpenAI Platform](https://platform.openai.com/api-keys)
2. Add it to your `.env` file
3. The service is configured in `src/services/RecipeService.ts`

### TensorFlow Configuration

The image recognition service is configured in `src/services/ImageRecognitionService.ts`. The current implementation includes:
- Ingredient detection capability
- Support for common foods (vegetables, meats, grains, etc.)
- Integration with device camera and photo library

## 🧮 Calorie Calculator

The built-in calorie calculator provides:

- **TDEE Calculation**: Total Daily Energy Expenditure based on age, weight, height, gender, and activity level
- **Macro Calculations**: Protein, carbs, and fat recommendations based on health goals
- **Recipe Nutrition**: Per-serving nutritional information for all generated recipes
- **Goal-Based Recommendations**: Calorie targets for weight loss, muscle gain, or maintenance

## 🔒 Privacy & Security

- API keys are stored in environment variables (not committed to git)
- User preferences are stored locally on the device using AsyncStorage
- No personal data is sent to external servers except OpenAI for recipe generation
