# Asset Placeholders

This directory contains placeholder files for app assets. In a production environment, you would replace these with actual image assets.

## Required Assets

- `icon.png` - App icon (1024x1024 px)
- `splash.png` - Splash screen image (2048x2048 px)
- `adaptive-icon.png` - Android adaptive icon (1024x1024 px)
- `favicon.png` - Web favicon (48x48 px)

## Generating Assets

You can use tools like:
- [Expo Icon Generator](https://www.npmjs.com/package/expo-icon-generator)
- Adobe Photoshop or Illustrator
- Online tools like Canva or Figma

## Asset Guidelines

- Use high-resolution images for better quality on all devices
- Keep file sizes optimized for faster loading
- Follow platform-specific guidelines (iOS and Android)
